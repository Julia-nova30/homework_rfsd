# Анализ финансовой отчетности из датасета RFSD

## Описание проекта
Экспресс-анализ случайной выборки данных из репозитория RFSD. По условиям ТЗ объем данных ограничен первыми 20 колонками и 1000 строками с применением потокового чтения 

## Выполненные задачи:
1. Оптимизировано чтение Parquet-файла через стриминг в Polars
2. Рассчитана описательная статистика числовых переменных
3. Построены гистограммы распределения, выявлены аномалии и выбросы отрицательные активы в line_1200
4. Построена матрица корреляции Пирсона - выявлена связь 0.88 между оборотными активами и запасами
5. Построена диаграмма рассеивания и сформулированы экономические выводы

## Как запустить:
1. Склонировать репозиторий `git clone ...`
2. Создать и активировать окружение `python3 -m venv venv`
3. Активировать окружение `source venv/bin/activate`
4. Установить зависимости `pip3 install -r src/requirements.txt`
5. Открыть ноутбук `src/analysis.ipynb`
